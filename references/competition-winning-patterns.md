# Competition Winning Patterns

> 基于国赛国一论文（2022-2024）和美赛 MCM/ICM O 奖论文（2004-2024）的系统性分析。
> 阅读时间：5 分钟。建模过程中反复参考此文件。

## 1. 摘要：90 秒决定生死

评委在每篇论文上平均只花 90 秒。摘要必须**完全自包含**，让评委不读正文就能判断论文价值。

### 黄金结构（国一 / O 奖通用）

| 段落 | 占比 | 写法 | 反例 |
|------|------|------|------|
| 问题重述 | 20% | **用建模语言重新表述**，不照抄原题 | ❌ "本题要求解决资源分配问题" |
| 模型体系 | 50% | "总-分"结构，分号分隔各阶段：<br>"针对……首先建立……然后引入……最后通过……" | ❌ 仅列模型名："使用了TOPSIS、熵权法" |
| 结果摘要 | 30% | **量化对比**：不仅给绝对值，必须与基线比较 | ❌ "总成本为285万元"<br>✅ "相较基线降低32%（285 vs 420万元），关键突破在路径拓扑优化" |

### 技术动词暗示创新

| 普通动词（减分） | 技术动词（加分） |
|---|---|
| 采用、使用、建立 | **融合、耦合、重构、嵌入、级联** |
| 分析、计算 | **剖分、溯源、逐层剥离** |
| 优化 | **自适应调谐、动态松弛、分治逼近** |

### 写摘要的铁律

1. **最后写**：正文+结果全部定稿后再写摘要
2. **反复打磨至少 5 遍**：每一遍删掉废话、补上数据
3. **不出现图表、公式编号、参考文献标注**
4. **国赛 400 字以内（中文），美赛 200-250 词（英文）**

## 2. 层次化建模：拒绝"一个模型万能"

### O 奖论文的建模规律

- **85% 的 O 奖论文使用自主改进模型**，而非直接套用标准算法
- 典型模式：**"经典方法 + 针对性改进"** — 如"GM(1,1) + 马尔可夫修正"、"遗传算法 + 变邻域局部改进"
- **层次化深入**：问题拆解 → 假设论证 → 模型迭代 → 决策推演

### 竞赛论文的"正确"建模姿态

```
第一层：基础基线（证明你能做）
  → 线性回归 / 熵权法 / 最短路 / 简单微分方程

第二层：竞争基线（证明你做得对）
  → 发现基线的显著缺陷 → 引入针对性的改进机制

第三层：冠军模型（证明你做得比别人好）
  → 公平对比（相同数据、相同预算、相同指标）
  → 结构验证（不是仅靠低残差和高R²）
```

### ❌ 错误堆叠示范（以下写法直接宣告出局）

- "本文综合使用了 TOPSIS、熵权法、灰色预测、遗传算法、BP 神经网络"——**没有解释为什么**
- "采用 LSTM 进行预测"——**小样本（<100）用 LSTM = 评委一眼看穿**

## 3. 验证章节：国二和国一的真正分水岭

### 必须出现的三类验证

| 验证类型 | 具体做法 | 占比要求 |
|----------|----------|----------|
| **灵敏度分析** | 核心参数 ±10% / ±20% / ±30%，输出变化曲线 | 至少 2 个参数 |
| **模型对比** | 与基线/文献方法对比，同一数据、同一指标 | 至少 1 个基线 |
| **鲁棒性检验** | 蒙特卡洛模拟 / Bootstrap / 极端场景测试 / 交叉验证 | 至少 1 种方法 |

### 灵敏度分析的写作模板

```
为验证模型的稳健性，我们对关键参数 α 和 β 分别进行灵敏度分析。
将 α 从基准值 λ₀ 以 ±10%、±20%、±30% 的幅度扰动，
结果显示：在 ±20% 范围内，目标函数变化不超过 5.3%，
表明模型对参数 α 不敏感，具有较好的鲁棒性。
但当 α 偏离超过 30% 时，解的质量快速退化（附图3），
这说明在实际应用中需要确保 α 的估计精度在 ±20% 以内。
```

### 蒙特卡洛模拟的量化报告

```
进行 10,000 次蒙特卡洛仿真，输入参数服从给定分布：
- 均值成本：285.3 万元（95% CI: [267.1, 303.8]）
- 5% 分位数（乐观）：248.7 万元
- 95% 分位数（悲观）：321.4 万元
- VaR₉₅ = 36.1 万元（相对于均值的最大可能超支）
```

## 4. 图表标准：竞赛级的硬要求

### 数量与质量

- O 奖论文：每 10 页 6-8 幅图表
- **每张图必须有且仅有一个主结论**
- 图表在正文中必须以"如图X所示"引用，而非"见下图"

### 必须包含的图表类型（竞赛最低标准）

1. **问题分析框架图** — 展示子问题拆解和依赖关系（流程图/框图）
2. **算法流程图** — 核心求解步骤的可视化（伪代码或流程图）
3. **主结果对比图** — 不同方法的性能对比（柱状图+误差线）
4. **灵敏度分析图** — 参数-响应曲线或热力图
5. **预测/趋势图** — 拟合值与真实值对比，标注验证集分界线

### 图表格式硬规范

- 统一使用三线表
- 图题在下方、表题在上方
- 配色方案统一（推荐 Wong's color palette）
- 导出 300 dpi PNG + 可编辑 SVG/PDF
- 中文论文：宋体/黑体，英文论文：Arial/Helvetica

## 5. 问题重述与分析的"潜规则"

### 不要照抄原题

需要做的是：
1. **用自己的语言重新组织**问题背景
2. **拆解出清晰的子问题**并用流程图展示依赖关系
3. **分析每个子问题的数学特征**（如"非线性""小样本""图结构""多目标"）
4. **为每个特征匹配合适的方法**，形成"具体问题 → 数据特征 → 选择模型 → 预期输出"的逻辑链

### 国一论文的典型特征

- 开篇第一段就列出"本文的主要贡献"或"本文的创新点"
- 每个子问题用独立的章/节，有完整的"建模→求解→结果"闭环
- 模型假设不仅列出，还在后文用数据验证其合理性

## 6. 选题策略（比赛开始前 30 分钟）

### 两大原则

1. **不选最难的，选最适配团队背景的**
   - 如果团队有物理/工程背景 → A 题（连续型）
   - 如果团队有算法/数据背景 → B/C 题（优化/大数据）
   - 注意：大数据题竞争最激烈，O 奖/国一产出率反而低

2. **模糊=机会**
   - 赛题中的每一个模糊概念，都是你展示创新性的切入点
   - O 奖获奖论文：主动界定模糊边界，自创子概念
   - 案例：某 O 奖论文自创"抽样零 vs 结构零"概念→直接拔高论文深度

### 快速选题检查清单

- [ ] 能用一句话说清"谁面临什么决策困境，我们的模型如何帮助解决"？
- [ ] 团队的数学/编程/写作长板能否在这个题目上充分发挥？
- [ ] 模型的结果能否转化为可操作的建议（不能只给数学结论）？

## 7. 参考文献：被忽视的加分项

- O 奖论文平均引用 **15-20 篇**参考文献
- 核心算法和重要参考必须引注
- 引用需规范（国赛用 GB/T 7714，美赛用 APA/MLA）
- **不要只引用教科书**—至少引用 2-3 篇近 3 年的期刊/会议论文

## 8. 常见致命错误（直接排除出奖）

| 错误 | 严重程度 | 说明 |
|------|----------|------|
| 数据虚构 | **一票否决** | 编造数据或结果，立刻零分 |
| 模型胡乱堆砌 | 致命 | 无理由使用 5+ 种模型，每种只用一次 |
| 无验证章节 | 致命 | 没有灵敏度分析、没有基线对比 |
| 结果无单位 | 严重 | "成本为 285" — 285 元？百万？吨？ |
| 图表编号混乱 | 严重 | 手动编号，正文引用不一致 |
| 摘要写成引言 | 严重 | 摘要应独立可读，不依赖正文 |
| 用"见下图"引用 | 中等 | 必须用"如图3所示" |
| 公式不编号 | 中等 | 核心公式必须编号，方便引用 |

## 9. 时间分配建议（72 小时竞赛）

| 阶段 | 时间 | 关键产出 |
|------|------|----------|
| 选题+问题理解 | 0-4h | 选题决策、子问题拆解图 |
| 第一问建模+求解 | 4-16h | 基础基线模型+可运行代码 |
| 第二问建模+求解 | 16-28h | 竞争基线、模型升级 |
| 第三问建模+求解 | 28-40h | 完整模型链、跨问一致性 |
| 验证与灵敏度 | 40-48h | 灵敏度图、对比表、极端场景 |
| 论文写作（草稿） | 48-60h | 完整初稿，所有图表就位 |
| 打磨与定稿 | 60-70h | 摘要打磨、格式统一、引用补全 |
| 最终检查 | 70-72h | 逐页检查、提交材料核对 |
